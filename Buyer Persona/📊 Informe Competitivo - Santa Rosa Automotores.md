## 📊 PARTE 1: DATOS DE VENTAS — ⚠️ REQUIERE DATA REAL

> **⚠️ IMPORTANTE:** El archivo `data/sample_sales/ventas.csv` contiene **datos de ejemplo generados sintéticamente** por `scripts/generate_sample_data.py`. NO son ventas reales. El sistema está diseñado para que cargues tu CSV real de ventas en `data/` y configures la ruta en `config/settings.yaml`. Una vez que se carguen las ventas reales, este análisis debe regenerarse.
>
> Para cargar tus ventas reales: exportá desde tu CRM/Bitrix24 un CSV con las columnas: fecha, producto, marca, categoría, cantidad, ingresos, email del cliente, edad, género, ciudad, canal. Colocalo en `data/mis_ventas.csv` y actualizá `settings.yaml → paths.sales_history`.
