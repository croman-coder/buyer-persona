# 💬 WhatsApp - Renew Ford
**Persona:** [[Renew Ford]]

> [!info] Cuándo usar cada mensaje
> Bienvenida, seguimiento y respuestas van dentro de las **24 horas** desde el último mensaje del cliente. Fuera de esa ventana, WhatsApp solo deja escribir con una **plantilla aprobada por Meta** (categoría marketing) y a quien aceptó recibir mensajes: esa es la invitación. `{asesor}` y `{nombre}` se completan al enviar. Sin tasas, plazos, garantías ni urgencias: la oferta del mes y el stock van al final, para confirmar antes.

## Bienvenida (cuando el cliente escribe)
```
¡Hola! 👋 Soy {asesor}, de Renew. Gracias por escribirnos por Ford usados certificados.

¿En qué te ayudo?
• Unidades disponibles
• Precio y formas de pago
• Coordinar una visita para verlo y probarlo

Contame y te respondo por acá 😊
```
## Seguimiento (dentro de las 24 horas)
```
¡Hola! Te escribo por Ford usados certificados. ¿Te gustaría venir a ver las unidades esta semana? Decime el día y el horario y te espero 🚗
```
## Invitación (plantilla de marketing, fuera de las 24 horas)
```
Hola {nombre} 👋 Te invitamos a conocer Ford usados certificados en persona: coordiná tu visita y probalo antes de decidir. ¿Te reservo un turno?

Si no querés recibir más mensajes, respondé BAJA.
```
## Respuestas rápidas
### Si pregunta por el precio
```
El precio depende del año, el kilometraje y la versión. ¿Qué estás buscando? Te paso las unidades disponibles con su precio 👍
```
### Si pregunta por el test drive
```
¡Genial! 🎉 Decime día, horario y sucursal, y te espero para que veas la unidad y la pruebes.
```
### Si pregunta por la financiación
```
Te calculamos la cuota según la versión y la forma de pago que prefieras. Para la aprobación te vamos a pedir la documentación habitual (cédula y comprobante de ingresos). ¿Querés que te llamemos? Financiación sujeta a aprobación crediticia.
```
### Si pregunta por su usado como parte de pago
```
Sí, podemos evaluar tu usado como parte de pago. Pasame marca, modelo, año y kilometraje, y te damos una cotización 👍
```
